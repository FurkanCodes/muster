# Label

A ticket's label, as its tracker gives it, shown as a quiet tag.

**Anatomy.** `mu-label`: `size-badge` (18px) high, `space-6` sides, `radius-xs`, a `line-strong` hairline, 11px at 500 in `text-quiet`. Labels go together in `mu-labels`, `space-6` apart.

Labels come from trackers anyone can write to. Show them as their text alone, never in the tracker's colours, with control characters removed.

The same tag names where a plugin is from (built in, git, folder) and where a setting is set ("from muster.toml").
