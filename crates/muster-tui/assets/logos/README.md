# Agents' logos

The marks the terminal UI draws before each session's name, so the person
sees at a glance which agent a chat is with. Each is a 64-pixel PNG
rendered from the SVG beside it by `scripts/render-logos.sh`.

| File | Agent | Source |
|---|---|---|
| `claude` | Claude Code | [Simple Icons](https://simpleicons.org) 15.21.0, `claude` (CC0-1.0), in Claude's orange `#D97757` |
| `gemini` | Gemini CLI | Simple Icons 15.21.0, `googlegemini` (CC0-1.0), in Gemini's blue-to-rose gradient |
| `codex` | Codex | Simple Icons 15.21.0, `openai` (CC0-1.0), white on a dark tile |
| `copilot` | Copilot CLI | Simple Icons 15.21.0, `githubcopilot` (CC0-1.0), white on a dark tile |
| `opencode` | OpenCode | OpenCode's own mark, `packages/console/app/src/asset/brand/opencode-logo-dark-square.svg` in [anomalyco/opencode](https://github.com/anomalyco/opencode) (MIT), on a dark tile |

The logos are their owners' trademarks. Muster shows them only to name the
agents it runs, and claims no endorsement.
